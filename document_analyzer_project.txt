INTERN PROJECT TASK

Project Title

AI Document Analyzer

Project Objective

Develop a web application that allows users to upload documents and automatically extract, analyze, summarize, and search the content.

The project must be developed WITHOUT any paid API keys.

Technology Stack

Frontend: HTML, CSS, JavaScript / React.js

Backend: Python Flask or FastAPI

Database: SQLite / Firebase

OCR: Tesseract OCR

PDF Processing: PyMuPDF

DOCX Processing: python-docx


Main Features

1. User Login

User Registration

Login

Logout

Protected Dashboard


2. Document Upload

Users should be able to upload:

PDF

DOCX

TXT

JPG

PNG


Display:

File name

File type

File size

Upload date

Processing status


3. Text Extraction

Extract text automatically from:

PDF

DOCX

TXT


For scanned PDFs or images, use OCR to extract the text.

4. OCR

Implement OCR using Tesseract.

The system should:

Detect scanned documents

Extract text from images

Display extracted text

Handle OCR errors properly


5. Keyword Extraction

Automatically identify important keywords from the document.

Example:

Input: "Python developer with experience in Django, Flask and PostgreSQL."

Keywords:

Python

Django

Flask

PostgreSQL

Developer


6. Summary Generation

Generate a short summary of the uploaded document.

Display:

Short Summary

Key Points

Important Information


The summary should work without paid AI APIs. The intern can use an open-source/local NLP approach.

7. Important Information Extraction

Extract useful information such as:

Names

Email addresses

Phone numbers

Dates

Companies

Locations

Amounts

Percentages


8. Search Within Document

Users should be able to search for any word or phrase inside the document.

Example:

Search: "salary"

Display:

Number of matches

Matching text

Page number where possible

Highlight searched keyword


9. Document Dashboard

Create a dashboard showing:

Total Documents

Processed Documents

Processing Documents

Failed Documents

Recent Documents


10. Document History

Users should be able to:

View uploaded documents

Search documents

Filter documents

Open document analysis

Delete documents

Re-analyze documents


11. Document Analysis Page

For every uploaded document, display:

Document Name
File Type
Pages
Word Count
Summary
Keywords
Important Information
Extracted Text
Search Option

12. Export

Allow users to export the analysis as:

PDF

TXT
